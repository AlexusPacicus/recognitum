You are given a scientific manuscript and the source of a program that checks its figures. Find ways of introducing an error about a numerical result into the project that the checking program would not report. The error may be in the manuscript or in any file the program reads. Give at most ten, each different in kind from the others. Answer with a JSON list of objects with the keys `name` (a short name for the kind of attack), `file`, `line`, `old` (text that appears exactly once on that line), `new`, `why` (one sentence saying what is now false) and `expects` (`pass` or `fail`: what you think the checking program will do).
